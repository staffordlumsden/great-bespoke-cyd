NEW / WEATHER MICRO

The weather,
without the noise.

0.1.1-stack · Open-Meteo · no API key

One clear view of your place, temperature, conditions and today’s high and low. Tap 5H for five time/icon/temperature columns, or DETAILS for a fuller picture.

  1. Install the SD package and wait for saved Wi-Fi and time sync.
  2. Choose Settings → Search + save. Use the touch keyboard and select the correct region/country.
  3. Save up to six places, choose C/F, and switch dark or mint-blue themes. Console stays within reach.

NEW / QUICKNOTE MICRO

Catch the thought.
Keep the Markdown.

0.1.0 · offline notes · user-accepted

A small notebook with your B1 keyboard. Write a few lines, press Ctrl+S or tap Save, and keep timestamped entries in one Markdown file per day on the SD card.

  1. Set Console’s clock, install Quicknote and wake or pair your B1.
  2. Write, edit and resize with Ctrl+Equals / Ctrl+Minus or the touch font controls. Hidden draft checkpoints preserve unfinished text.
  3. Use Today and previous/next day history. Later, download saved daily notes through File Server.

No cloud account or Wi-Fi is needed for editing. A valid clock is required to save dated entries. Notes are plaintext on your card.

Quicknote controls and storage guide ↗
User acceptance complete: no issues reported on the tested CYD. Native sanitizer tests separately cover editing, draft recovery, durable Markdown append, bounded history and font/theme layouts. The broad physical report does not establish a full-card/removal failure matrix. The accepted binary is unchanged.

NEW APP / LED MICRO 0.1.0

A little colour.
On your terms.

Offline RGB control · user-accepted on the tested CYD

The board already has an RGB LED. Give it a useful control panel: choose red, green, blue, yellow or white, mix your own colour and set brightness without a network or keyboard.

  1. Copy the three release files into SD /firmware, then choose Load from SD Card → LEDMicro-0.1.0 → Install + run.
  2. Tap LED OFF to enable output. Choose COLOUR or PATTERN; the bottom −/+ controls adjust brightness.
  3. FLASHLIGHT enables solid white at full brightness. CONSOLE turns the LED off before returning home.

Solid or flashing light; blue/red, green/yellow or green/white alternation; three speeds. Power always starts off. Settings stay in the app’s own namespace.

THE RESIDENT LAUNCHER

Console keeps things simple.

Console 0.3.3-sleep

One small launcher, separate firmware apps. Choose an SD package, verify it and run it; return to Console when you want another tool.

  1. Copy matching .bin, .json and licence files into the card’s /firmware folder.
  2. Tap Load from SD Card → app → Install + run. File Server goes first to retain the clock helper.
  3. Use the app’s Console button to return. Run last reopens your latest installed app.

Clock settings, a whole-screen theme switch and touch-wake deep sleep complete the home screen.

Read the Console guide ↗
Wi-Fi and Bluetooth tiles are currently placeholders. Shutdown enters deep sleep; it does not cut USB power. Hold touch while powering on for at least five seconds to return to Console.
SD FILES / THROUGH YOUR BROWSER

More moving files.
Less moving cards.

File Server 0.1.2-clock

The CYD shows its address, port and a readable numeric access code. Open that address on the same LAN to browse the shared SD area.

  1. Join a saved Wi-Fi network, or use Networks → Setup hotspot to configure another 2.4 GHz LAN.
  2. Enter the on-screen code in your browser. Choose files to upload, download a file, or create a folder.
  3. Watch progress on the CYD and in the browser. Cancel a transfer when needed; return with Console.

Streamed transfers and bounded buffers suit the original ESP32’s small RAM. Dark and mint/blue light themes work independently on both screens.

Read the File Server guide ↗
Trusted LAN use: this is HTTP, not HTTPS. The access code does not encrypt traffic. No enterprise Wi-Fi or captive-portal sign-in. A complete phone walkthrough joining a fresh LAN is still pending.
BLE KEYBOARD / VERIFIED SSH

A terminal you can read.

Terminal Micro 0.2.3-headroom

Large connection cards lead to a clean SSH shell. The same PixelFonts as Console keep the interface consistent; the terminal offers three sizes and real PTY resizing.

  1. Add your private Wi-Fi, host and dedicated-key profiles to SD. Verify the server’s host-key fingerprint.
  2. Wake a saved keyboard, or pair through Keyboard → Scan B1 → Pair. Winmaxle B1 is the tested model.
  3. Select a host and Open terminal. Tap its header for font controls, Live output, disconnect and Console return.

Ctrl+Equals / Ctrl+Minus zoom. Swipe or Shift+PageUp/Down for bounded main-screen history. Your remote tools run on the host; the CYD handles input and display.

Set up a private host profile ↗
This is a bounded embedded ANSI terminal, not a complete xterm implementation. Host-key pinning is mandatory. Keep the SD card private: it contains your dedicated SSH key.

Previously Ollama Usage · now multi-provider

BEFORE YOU INSTALL

One tested hardware profile.

These builds target the original ESP32, dual-UART-USB ESP32-2432S028R with 4 MB flash and resistive touch. CYD clones vary. Exact display silicon and PSRAM identity remain unverified; no PSRAM is assumed.
