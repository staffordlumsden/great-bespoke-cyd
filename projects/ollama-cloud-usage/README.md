# Ollama Usage is now Usage

Ollama Usage 0.1.0 was renamed **Usage 0.2.0**, adding Codex, optional OpenRouter
and custom feeds. See [the current app](../usage/README.md). The original
[0.1.0 release](https://github.com/staffordlumsden/great-bespoke-cyd/releases/tag/ollama-usage-v0.1.0)
remains available; its source is preserved in that tag. Private configuration
migration and pending hardware checks are explained in the new guide.
